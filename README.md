# Anza Open six

Open-source electric guitar that anyone can build cheaply.
Aluminum, plastic, wooden.

## Goal
A guitar that costs a fraction of a regular one, so talent
isn't blocked by a $100 price tag.

## Status
Early design stage. Working on a universal neck shoe
compatible with Fender-style necks (Telecaster pocket).
